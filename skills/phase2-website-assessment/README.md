# Phase 2 Website Assessment

A slot-agnostic workflow skill for daily website assessment/redesign work. It requires a live assigned slot and uses authoritative assignment data, idempotent return evidence, read-only same-day benchmarking, source preservation, evidence-based QA, and safe scoped commits. See [`SKILL.md`](SKILL.md) for the entry point.

This skill is adjacent to [`website-poc-generator`](../website-poc-generator/SKILL.md), which generates the three candidate HTML concepts. Phase 2 performs assigned assessment/redesign work after candidate generation/handoff as directed by the live orchestrator.
