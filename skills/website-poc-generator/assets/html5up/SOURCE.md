# HTML5 UP reference bundle

This folder contains the complete Forty, Landed, and Story template downloads used as offline scaffold references by the website-poc-generator skill.

- Forty: https://html5up.net/forty and https://html5up.net/forty/download
- Landed: https://html5up.net/landed and https://html5up.net/landed/download
- Story: https://html5up.net/story and https://html5up.net/story/download
- License: Creative Commons Attribution 3.0 Unported, included separately in each template's `LICENSE.txt`.
- Workflow source snapshot: `chatgpt_automation/templates/html5up/` at commit `5ce8c97aef4741e3615262720cb4a9eacd0476d9`.

The full official packages supply the images, JavaScript, fonts, Sass, auxiliary CSS, and example pages omitted from the workflow's compact bundle. Each package's `index.html`, `assets/css/main.css`, `LICENSE.txt`, and `README.txt` are synchronized to that workflow bundle; the CSS content may differ only in line endings. Keep the full files and notices together when redistributing these reference assets.

Use demo images and scripts only to inspect template structure and behavior. They are not automatically approved for a generated business page. Keep the generated HTML standalone and follow the skill's separate image provenance, attribution, and JavaScript requirements.
